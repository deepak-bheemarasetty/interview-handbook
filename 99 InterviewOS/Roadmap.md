## Architecture

```
Brain (Rules)     →  .cursor/rules/
Memory (State)    →  99 InterviewOS/ (Progress, Confidence, Weak Areas, ...)
Planner           →  Curriculum.md
Teacher           →  Handbook (numbered folders)
Coach             →  Interview Rules, Feedback, History/
```

The handbook owns knowledge. The mentor owns reasoning. Memory files own state.
