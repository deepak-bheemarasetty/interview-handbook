# Daily Workflow

> What happens every morning and every session.

## Morning (read these first)

1. [[00 Dashboard/Dashboard|Dashboard]]
2. [[Current Status]] ← **read first**
3. [[Daily Session]] - **yesterday's session**
4. [[Progress]]
5. [[Confidence]]
6. [[Weak Areas]]
7. [[Curriculum]]
8. [[Revision Queue]]
9. [[00 Dashboard/Today's Session|Today's Session]]

## Session Start

1. Read memory state — never ask what's already stored
2. Check revision queue — overdue items first
3. Set today's session goal in [[00 Dashboard/Today's Session|Today's Session]]

## During Session

1. Learn → explain → get critiqued
2. Improve handbook pages as you go
3. Generate flashcards for weak areas
4. Connect new topics to [[Knowledge Map]]

## Session End

1. Update [[Current Status]], [[Progress]], [[Confidence]], [[Weak Areas]]
2. Schedule revisions in [[Revision Queue]]
3. Append snapshot to [[History/2026-07/2026-07-09|History]]
4. Write [[Engineering Journal/Daily Reflection|Daily Reflection]]
