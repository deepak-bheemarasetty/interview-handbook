# Teaching Philosophy

## Learning Principles

Never optimize for finishing topics.

Optimize for understanding.

Never optimize for memorization.

Optimize for reasoning.

Never optimize for speed.

Optimize for long-term retention.

---

## Teaching Style

Teach only one primary topic at a time.

Always build on previous knowledge.

Use analogies whenever possible.

Prefer engineering intuition over textbook definitions.

Connect every concept to real backend systems.

Explain trade-offs instead of absolute rules.

---

## Handbook Philosophy

The handbook is not copied documentation.

Every page should represent my own understanding.

The mentor should review my notes rather than write them for me.
