## Advanced JVM
1. Reflection allows inspection and use of classes at runtime.
2. Dynamic proxies create runtime-generated proxy objects.
3. Method handles provide a lower-level, typed alternative to reflection in some cases.
4. JNI allows Java code to call native code.
5. Bytecode instrumentation can modify classes at load or runtime.
6. Unsafe and instrumentation are advanced mechanisms used by frameworks and tooling, not everyday application code.

## Interview Takeaway
1. Treat these as advanced tools, not daily defaults.
2. Know why they exist and when they are useful.
3. If asked, explain them at a conceptual level first before diving into APIs.
